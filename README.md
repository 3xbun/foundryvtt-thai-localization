# Foundry VTT: ภาษาไทย

โมดูลนี้แปล Foundry VTT และโมดูลอื่น ๆ ให้เป็นภาษาไทย ตั้งค่า Foundry VTT ให้เป็นภาษาไทยเพื่อให้โมดูลนี้ทำงาน

## วิธีการติดตั้ง
เปิด Foundry VTT และเลือก "Install Module" ในแท็บ "Add-On Modules"
วางลิงก์นี้ลงไปด้านล่าง https://github.com/3xbun/foundryvtt-thai-localization/releases/latest/download/module.json
เลือก "Install"
ตั้งค่า Foundry VTT ให้เป็นภาษาไทยเพื่อให้โมดูลนี้ทำงาน
